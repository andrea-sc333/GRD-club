# Website Build Brief
 
## 1. Project Overview
 
Describe the website, its purpose, and its audience.
 
## 2. Design Reference
 
Identify the Figma file and intended page frame.
 
Describe the verified design information available.
 
## 3. Page Structure
 
List every section in order.
 
For each section, document:
- Purpose
- Content
- Layout
- Typography
- Colours and background
- Assets
- Important spacing and alignment
 
## 4. Design System
 
Document the colours, typography, spacing,
content widths, buttons, and reusable components.
 
## 5. Assets
 
List the required images, logos, icons, and fonts.
 
Identify the intended use of each asset.
 
## 6. Technical Requirements
 
Specify HTML, CSS, JavaScript, file organization,
accessibility, and any necessary interactions.
 
## 7. Responsive Behaviour
 
Describe the intended desktop, tablet, and
mobile layouts.
 
## 8. Acceptance Criteria
 
List the visual, technical, responsive, and
functional requirements for completion.
 
## 9. Outstanding Questions
 
Record missing information or decisions that
must be resolved before final approval.
